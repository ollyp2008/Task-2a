Learn Area: Mini Examples

Each mini example shows the correct HTML pattern (label, input, error area) and lets you run one validation check. Test each example with a PASS and a FAIL and record it in your testing log.

A) Presence check example

Try leaving this blank, then type a name.

B) Digit check example

Try digits only, then try letters or spaces.

C) Format check example (email)

Try name@example.com, then try missing the @ symbol.

D) Range check example (1 to 5)

Try 0, then 3, then 6.

E) Length check example (max 20 characters)

Try a short message, then try a message longer than 20 characters.

Minimum evidence: record at least one PASS and one FAIL for each mini example (A to E).
