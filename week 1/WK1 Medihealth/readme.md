
# MediHealth — Appointment Booking & Interactive Health Tips

A lightweight, client-side web app for **MediHealth**, a company specialising in basic healthcare services. The app enables patients to **book, reschedule, and cancel appointments** and provides **interactive health tips** through an accessible, high-contrast, mobile-friendly interface. Data is persisted via **Supabase REST** with recommended security policies.

---

## 📌 Project Description
The software development company has secured a new contract to deliver a digital solution for **MediHealth**, whose services include:

- **Basic health check-ups**
- **Online appointment scheduling**
- **Health advice and tips** via their website

### Objectives
- **Simplify appointment scheduling**
- **Provide health tips to users in a more interactive way**
- **Enhance user experience** on their platform

### Key Features
- **Online Appointment Booking** — Users can schedule, reschedule, and cancel appointments via a simple form.
- **Interactive Health Tips** — Personalized health tips (future scope) based on profile and preferences.
- **Enhanced Navigation** — Intuitive, single-column portrait layout with accessible headings and focus styles.

---

## 🧱 Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6)
- **Backend (BaaS)**: Supabase REST API (PostgREST)
- **Data Storage**: Supabase Postgres
- **Deployment**: Any static host (GitHub Pages, Netlify, Vercel) or local dev server
